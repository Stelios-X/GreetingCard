# GreetingCard 📱✨

A modern Android application built with **Kotlin** and **Jetpack Compose**, created as part of the official Android Basics with Compose curriculum.

## 🚀 Overview

This project marks the start of my journey into native Android development. It demonstrates the fundamentals of declarative UI building in Jetpack Compose, state-free composable functions, custom theming, and live design previews.

## 🛠️ Tech Stack & Tools

- **Language:** [Kotlin](https://kotlinlang.org/)
- **UI Toolkit:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Material 3)
- **Build System:** Gradle (Kotlin DSL)
- **IDE:** Android Studio

## ✨ Key Features & Concepts Practiced

- **Declarative UI:** Building layouts using `@Composable` functions (`Text`, `Surface`, `Scaffold`).
- **UI Customization:** Applying background colors, padding modifiers, and Material 3 theme configurations.
- **Live Previews:** Utilizing `@Preview` annotations to iterate on UI designs rapidly without deploying to an emulator.
